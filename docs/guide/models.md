# Models и libs

Две вспомогательные части проекта, которые не являются слоями схемы, но есть почти везде.

---

## Models — `internal/models/`

**Что это.** Сущности предметной области: `Order`, `User`, `Invoice`. Их создают и меняют обработчики, их сохраняют сервисы.

**Что можно класть в модель:**
- **Поля и теги библиотек**, которые с ней работают: `json` для ответа, `bun` для базы. Сервис, принимающий `any`, сам читает имя таблицы и колонки из тегов. Так модель выполняет его «контракт», а сервис о моделях не знает.
- **Поведение самой сущности:** `order.Total()`, `user.HashPassword()`. Когда это вызывать, решает обработчик.

```go
// internal/models/order.go
type Order struct {
    bun.BaseModel `bun:"table:orders" json:"-"`

    ID        string    `bun:"id,pk" json:"id"`
    Owner     string    `bun:"owner,notnull" json:"owner"`
    Item      string    `bun:"item,notnull" json:"item"`
    Qty       int       `bun:"qty,notnull" json:"qty"`
    CreatedAt time.Time `bun:"created_at,nullzero,notnull,default:current_timestamp" json:"created_at"`
}
```

**Правила:**
- **Модели — сущности предметной области**, а не параметры запросов. Параметры и результаты обработчиков живут рядом с обработчиками.
- **Сервисы моделей не импортируют.** Если сервису нужно поведение объекта, он объявляет у себя интерфейс, а модель его выполняет.
- **Структура свободная.** Плоские структуры — по умолчанию. Если модель обрастает тегами нескольких библиотек, разделите её на «чистые данные» и обёртки под библиотеки.

## Libs — `pkg/libs/`

**Что это.** Ваш переиспользуемый код без состояния: помощники, форматирование, общие алгоритмы. Импортируете и вызываете — без регистрации, без `Init` и `Stop`.

| | Libs | Services |
|---|---|---|
| Состояние | нет | может быть: соединения, настройки |
| Жизненный цикл | нет | `Init` и `Stop` в каталоге |
| Как получить | импортировать | геттер из `pkg/services` |
| Конфиг | нет | своя секция |

Если у кода появилось состояние или настройки, это уже сервис.

---

## Utils — `internal/utils/`

Помощники, которые нужны только этому проекту и знают его модели. Если помощник не зависит от проекта, его место — `pkg/libs/`.
