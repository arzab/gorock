Загрузчик конфигурационных файлов для Go с автоматическим маппингом в snake_case, подстановкой переменных окружения и валидацией структур.

## Обзор

`rockconfig` читает конфигурационный файл (JSON или YAML), маппит его значения в типизированную Go-структуру и проверяет наличие всех обязательных полей. Теги `json` или `yaml` не нужны — имена полей автоматически преобразуются в `snake_case`.

## Быстрый старт

```go
type Config struct {
    Host string
    Port int
    Debug bool `config:",omitempty"`
}

cfg, err := rockconfig.InitFromFile[Config]("config.yaml")
if err != nil {
    log.Fatal(err)
}
```

```yaml
# config.yaml
host: localhost
port: 8080
```

## Маппинг полей

По умолчанию имена полей структуры автоматически преобразуются в `snake_case`:

| Поле в Go    | Ключ в конфиге |
|--------------|----------------|
| `Host`       | `host`         |
| `Port`       | `port`         |
| `MyField`    | `my_field`     |
| `HTTPServer` | `http_server`  |
| `UserID`     | `user_id`      |

## Тег config

Используйте тег `config` для настройки поведения поля — аналогично `bun` или `encoding/json`:

```
config:"[name][,option[,option...]]"
```

| Тег                       | Поведение                                                    |
|---------------------------|--------------------------------------------------------------|
| _(без тега)_              | snake_case имя, поле обязательное                            |
| `config:"-"`              | поле полностью игнорируется                                  |
| `config:"host"`           | явное имя `"host"`, поле обязательное                        |
| `config:",omitempty"`     | snake_case имя, поле необязательное                          |
| `config:",default=8080"`  | snake_case имя, использовать `8080` если ключ отсутствует    |
| `config:",env=PORT"`      | snake_case имя, читать значение из переменной окружения `$PORT` |

Опции можно комбинировать (см. заметку об очерёдности ниже):

```go
type Config struct {
    Host    string        // обязательное, маппинг как "host"
    Port    int           `config:",default=8080"`       // необязательное со значением по умолчанию
    Debug   bool          `config:",omitempty"`           // необязательное, без дефолта
    Secret  string        `config:",env=APP_SECRET"`      // читается из $APP_SECRET
    Timeout time.Duration `config:",default=30s"`         // поддерживает строки duration
    Token   string        `config:"-"`                   // игнорируется
}
```

> **Важно:** `default=` должен быть **последней** опцией в теге, так как после `=` потребляется весь остаток строки как значение (это позволяет использовать запятые внутри значений по умолчанию, например `default=a,b,c`).

## Валидация

Поле **обязательно**, если у него нет `omitempty`, `default=` или `-`. Обязательное поле должно **присутствовать** в файле (или прийти из привязки `env=`). Значение может быть любым, включая нулевое:

```yaml
port: 0          # ok — 0 это значение
enabled: false   # ok — обязательные bool работают
tags: []         # ok
host: ""         # ошибка — обязательная строка не может быть пустой
# ключа нет      → ошибка
# ключ с null    → считается отсутствующим
```

Все проблемы сообщаются вместе. Пути — это ключи конфига, как они написаны в файле:

```
rockconfig: config.yaml: missing required fields:
  http.port
  database.password (empty)
unknown keys (typo? use rockconfig.AllowUnknownKeys() to ignore):
  http.request_timout
```

Тип ошибки проверяется через `errors.Is(err, rockconfig.ErrMissingFields)` / `errors.Is(err, rockconfig.ErrUnknownKeys)`.

### Неизвестные ключи

Ключи, которым не соответствует ни одно поле (включая ключи полей с тегом `-`), — ошибка: опечатка не откатится молча на значение по умолчанию. Если один файл читают несколько программ, передайте `AllowUnknownKeys()`:

```go
cfg, err := rockconfig.InitFromFile[Config]("config.yaml", rockconfig.AllowUnknownKeys())
```

### Pointer-поля

Указатель нужен, когда программе важно, было ли значение задано вообще: необязательный `*int` остаётся `nil`, если ключа нет, и равен `&0`, если задан 0.

## Переменные окружения

### Ссылки в значениях

Строковые значения могут ссылаться на переменные окружения. Подстановка выполняется **после** разбора файла, поэтому значение переменной не может изменить структуру файла.

```yaml
database:
  password: ${DB_PASSWORD}            # ошибка, если DB_PASSWORD не задана
  host: ${DB_HOST:-localhost}         # запасное значение, если не задана или пуста
  port: ${DB_PORT:-5432}              # строки приводятся к типу поля
  dsn: "postgres://${DB_HOST}/app"    # можно встраивать в строку
  hash: "$2a$10$..."                  # одиночный $ остаётся как есть
  template: "$${NOT_EXPANDED}"        # $${ — это литерал ${
```

> **Изменено:** раньше весь файл проходил через `os.ExpandEnv`: `$VAR` без скобок подставлялся, незаданные переменные молча становились `""`, а значения вроде `pa$$word` портились. Теперь пишите `${VAR}`.

### Явная привязка поля

Используйте `env=VAR_NAME` для привязки поля к конкретной переменной окружения. Это имеет приоритет над значением из файла:

```go
type Config struct {
    Secret string `config:",env=APP_SECRET"`
}
```

Если `APP_SECRET` не задана в окружении, используется значение из конфигурационного файла.

## Поддерживаемые типы

| Тип Go               | Поддержка | Примечания                                       |
|----------------------|-----------|--------------------------------------------------|
| `string`             | ✅        |                                                  |
| `bool`               | ✅        | `"true"`, `"false"`, `true`, `false`             |
| `int`, `int8..64`    | ✅        |                                                  |
| `uint`, `uint8..64`  | ✅        |                                                  |
| `float32`, `float64` | ✅        |                                                  |
| `time.Duration`      | ✅        | `"5s"`, `"1m30s"`; голые числа отклоняются        |
| `[]T` (slice)        | ✅        | Элементы следуют тем же правилам конвертации     |
| `map[K]V`            | ✅        | Рекомендуются строковые ключи                    |
| pointer на любой тип | ✅        |                                                  |
| вложенная структура  | ✅        | Маппится как вложенный объект в конфиге          |
| `interface{}`        | ✅        | Значение передаётся как есть                     |
| встраиваемая структура | ⚠️      | Обрабатывается как именованный вложенный объект  |

## Вложенные структуры

Вложенные структуры маппятся на вложенные объекты в конфигурационном файле:

```go
type Config struct {
    Server   ServerConfig
    Database DatabaseConfig `config:",omitempty"`
}

type ServerConfig struct {
    Host string
    Port int
}

type DatabaseConfig struct {
    DSN string
}
```

```yaml
server:
  host: localhost
  port: 8080
# database опущена — разрешено из-за omitempty
```

Если `database` присутствует в файле, её поля проверяются обычным образом даже при наличии `omitempty`.

Значения по умолчанию и привязки `env=` внутри секции применяются, даже если секции нет в файле. Необязательная pointer-секция (`*DatabaseConfig` с `omitempty`) остаётся `nil`, пока файл или env-привязка не зададут для неё значение.

## Добавление своих форматов

Реализуйте `Decoder` и зарегистрируйте его для нужного расширения файла:

```go
type Decoder interface {
    Decode(data []byte) (map[string]interface{}, error)
}

// Зарегистрировать до вызова InitFromFile.
rockconfig.RegisterDecoder(".toml", &MyTomlDecoder{})
```

`RegisterDecoder` безопасен для конкурентного использования.

## Ограничения

- **Встроенные (анонимные) структуры** обрабатываются как именованные вложенные поля, а не «разворачиваются». Используйте явные имена полей.
- **`default=` должен быть последним** в списке опций тега.
- **Duration** задаётся строкой с единицей (`"30s"`). Голое число отклоняется — иначе оно означало бы наносекунды.
- **`time.Time`** и другие структуры из чужих пакетов обрабатываются как вложенные объекты, что обычно не то, что нужно. Загружайте их строкой и парсите в коде.
